1.2.0较多更新
1、优化UI，扩大问题框和内容框
2、增加批量导入功能，并添加自动将CSV文件转换为json导入文件的python脚本（具体格式需要修改csv的列名以供识别转换）
3、增加一个知识点对应多个图片功能，以防止内容过少
4、修改图片显示功能

建议学习流程:
1、自行学习将问题，答案对应图片存入word
2、使用openclaw将word整理为csv+图片，csv内部按列对应排布好
3、使用python脚本，将csv转换为json
4、批量导入json，会自动复制图片到应用文件夹下，原先文件可以删除


# -
用于个人复习，可以储存文字图片，然后基于简略版艾宾浩斯记忆曲线定期提醒复习。
添加知识点分类，添加相关图片。之后每次打开exe，都会左侧列出今天要复习的内容。
文字储存在注册表，图片储存在.images中储存备份。
